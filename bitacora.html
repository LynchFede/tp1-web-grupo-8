Bitácora de Desarrollo

En esta sección se describe el proceso de desarrollo del proyecto, las decisiones tomadas por el equipo y la evolución del trabajo a lo largo de la implementación.

Decisiones de diseño

Desde el inicio se decidió implementar un diseño simple, claro y reutilizable. Se optó por una estructura modular utilizando componentes HTML para el header y el footer, lo que permitió mantener consistencia en todas las páginas.

Además, se trabajó con un diseño centrado, utilizando tarjetas para representar a cada integrante, priorizando la claridad visual y la organización del contenido.

Se incorporó también un modo oscuro para mejorar la experiencia del usuario y permitir una interacción más dinámica.

Dificultades encontradas

Una de las principales dificultades fue la reutilización de componentes entre distintas páginas, especialmente al trabajar con la carga dinámica del header y footer mediante JavaScript.

También se presentaron inconvenientes al manejar la ejecución del código en distintas páginas, ya que algunas funciones se ejecutaban en contextos donde los elementos no existían en el DOM.

Otro desafío fue la implementación del modo oscuro de manera global, asegurando que afecte a todos los elementos del sitio y se mantenga al navegar entre páginas.

Resolución de problemas

Para resolver estos inconvenientes, se incorporaron validaciones en JavaScript que verifican la existencia de los elementos antes de ejecutar funciones específicas.

Se utilizó localStorage para persistir el estado del modo oscuro, logrando que la preferencia del usuario se mantenga entre recargas y navegación.

Además, se reorganizó el código para mejorar su modularidad y reutilización, facilitando el mantenimiento del proyecto.

Cambios importantes

  • Implementación de tarjetas dinámicas generadas con JavaScript.
  • Incorporación de animaciones para mejorar la experiencia visual.
  • Modularización del header y footer mediante carga dinámica.
  • Implementación del modo oscuro persistente.
  • Mejora en la organización del CSS y adaptación responsive.

Reflexión y evolución

Este proyecto permitió aplicar conceptos fundamentales del desarrollo frontend, como la separación de responsabilidades, la reutilización de componentes y la mejora progresiva de la interfaz.

De cara al TP2, se espera continuar mejorando la estructura del código, incorporar nuevas funcionalidades y profundizar en la experiencia del usuario, manteniendo una evolución constante del proyecto.
